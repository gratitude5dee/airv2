# Create Kit maintenance

The Kit is a closed, pinned, licensed component set (V11 §12). Everything under
`packages/create-kit/` is generated by `scripts/harvest.ts` except `scripts/`,
`prompts/src/`, `evidence/`, `vendor/tarballs/`, `restricted/`, `functions/` and
`kit/air/index.ts`. Never hand-edit `kit/**`, `DESIGN.md`, `kit.lock.json`,
`kit.sources.json` or `prompts/create-agent.system.md` — edit the inputs and re-harvest.

Commands run from the repo root, offline (captures live in `evidence/<source>/upstream/`):

```bash
npx tsx packages/create-kit/scripts/harvest.ts            # full: normalize, measure, headless lite check, docs
npx tsx packages/create-kit/scripts/harvest.ts --only fancy/typewriter --skip-harness
npx tsx packages/create-kit/scripts/verify.ts             # what CI runs (.github/workflows/create-kit.yml)
npx tsc -p packages/create-kit/tsconfig.json
```

The headless check needs a Chromium: it finds playwright-core in the npx/bun cache
and `~/.cache/ms-playwright`, or set `KIT_PLAYWRIGHT` / `KIT_CHROMIUM`.

## Add a component

1. Check the license first. Only Tier A (MIT / MIT-with-evidence) sources enter git;
   the eligible sources and every exclusion are in `scripts/lib/sources.ts`. A new
   source needs a pin (commit or capture date) and evidence under `evidence/<source>/`
   before harvest will run (`placeLicenseEvidence` throws otherwise). Commons Clause,
   "free for personal use", unlicensed, or trade-dress-bearing material is Tier B or
   excluded — see `restricted/README.md`, do not add it to `kit/`.
2. Add a `ComponentSpec` to `scripts/lib/catalog.ts`: id `<source>/<name>`, upstream
   `files`, `deps` (bare specifiers, all must be in `vendor/sbom.json`), `litePolicy`,
   `touch`, `reducedMotion`, tags, and `when`. Add `patches` for source that references
   hosts, fonts, CDN scripts, proprietary icon packages (→ `lucide-react`), or
   `@/…` aliases the normalizer does not already rewrite. Add a `demo` when the harness
   cannot mount it with `{ text, children }`.
3. Capture the upstream bytes: `KIT_CLONE_<SOURCE>=/path/to/clone npx tsx … harvest.ts --refresh --only <id>`
   (registry and arlan sources fetch over the network instead). Captures are committed;
   a file that cannot be captured is a recorded gap in `kit.sources.json`, never
   hand-written source.
4. Run the full harvest, read the line it prints for the component (`lite`/`----`,
   js/css KiB, harness verdict), then `verify.ts`. A `lite` component must pass the CSP
   lint with no hard finding, render at 390×760 with WebGL disabled and reduced motion
   on, and keep the aggregate lite set under 300 KiB JS / 200 KiB CSS gzipped.
5. Commit `kit/<source>/<name>/`, the capture, `kit.lock.json`, `kit.sources.json`,
   `DESIGN.md`, `prompts/create-agent.system.md`, and
   `infra/template/skills/create-miniapp/DESIGN.md` together. Re-running harvest on
   the commit must produce no diff.

## Verify licenses

`verify.ts` fails on: a `kit/` file without a lock entry or with a changed hash, a
lock entry without a license tier, any Tier B marker (React Bits / CanvasUI / Commons
Clause) anywhere outside `restricted/` and `evidence/`, a component with a host
reference or hard CSP finding, a `lite` component the harness could not render, a
budget overrun, a vendor package younger than 7 days at SBOM time, or a generated doc
that does not match its inputs. Every lock entry carries `license.{spdx,tier,source}`
and the evidence path in `kit.sources.json` must exist.

## Vendor and Tier B

- Bump a runtime dep: replace the `.tgz` in `vendor/tarballs/` (`npm pack name@ver`),
  `npx tsx packages/create-kit/scripts/vendor.ts --sbom`, re-harvest (weights change).
- Tier B never enters git. `scripts/pack-restricted.ts` builds the private
  `_platform/kit/restricted/<version>.tgz` from a local React Bits checkout named in
  `restricted/allowlist.json`; the operator uploads it — see `restricted/README.md`.
