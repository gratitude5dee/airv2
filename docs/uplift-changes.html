M10

uiapidb

Today the box's power state is invisible: wake is implicit, stop belongs to a cron sweeper, and cold starts surface as error strings after a send fails. M10 exposes the lifecycle the orchestrator already runs — status, a manual power-on quick start in Chat, and a working power button on Computer. Stop is always graceful (C20/C6).

New routes: GET /api/box/status (safe projection — no URLs, tokens, or box IDs) · POST /api/box/stop (graceful only) · POST /api/box/wake {keep_awake_minutes}
Migration 0018_box_power.sql: widen boxes.state with starting / stopping (+ cost_events.kind gains stt for M13)
Chat boot banner: off → "Power on" → starting with elapsed time → collapses when ready; honest 429 start-limit state; composer never disabled
Computer tab header: status dot + "sleeps in · ", Power on/off, Keep awake 1h; asleep empty-state instead of a 502 iframe
Sidebar presence dot on the Computer nav item, driven by one shared status poll (5s in transition, 60s idle)

M12

Composio → Hermes continuity

apiboxinfra

Connections currently install into the box exactly once, on first activation — nothing refreshes a rotated session URL, nothing converges a re-forked box, and the agent is never told what its human connected. M12 replaces the one-shot install with an idempotent ensure, and gives the agent a readable manifest.

ensureComposioMcpInstalled(): hermes mcp list → add/update only on drift; called on first-active, on connectors sync, post-wake (fire-and-forget), and at provisioning
Agent awareness: write ~/.hermes/connected-tools.md on every status flip; SOUL.md gains one line pointing at it (template version bump)
Meta MCP folded in: same idempotence for hermes mcp add meta-ads — pressing setup twice yields one entry
Observability: structured ensure logs (none|added|updated) surfaced in /api/admin/ops

Secrets discipline unchanged: connected-tools.md carries display names only — no tokens, no account IDs, no URLs (goal.md §7.4 secrets test still passes verbatim).

M13

uiapidb

M16

The WZRD creative lane — /imagine · /animate · /zap

uiapidbbox

Ported from outsideairworker as a control-plane command lane that runs before the Hermes agent: parse → one strict Groq routing call → GMI Cloud generation → deliver, on web chat and iMessage. No box wake, no box-seconds, keys never leave the control plane. Prose requests still go to the agent; the lane owns only the explicit commands. Tier-2 senders can never trigger a paid generation (C23).

lib/creative/ port: parse (ambiguity fails deterministically) · router (openai/gpt-oss-20b, mode re-locked after) · prompts (v2 templates, VOICE + SAFETY) · GMI client (semaphore, 420s budget, submit_unknown never resubmitted) · SSRF media gate
Models kept verbatim: imagine → gpt-image-2-generate/-edit · animate → seedance-2-0-fast-260128 (720p, image = first frame) · zap → gemini-omni-flash-preview (≤5 img + ≤3 vid refs)
Migration 0021_creative_lane.sql: creative_jobs (status incl. submit_unknown; no prompt text stored — C4) + cost_events kind:'render' per delivery; daily cap
Web lane: /api/chat short-circuits to a creative_jobs row + SSE progress; result stored via creative_assets (sha256 dedupe) and served on a short-TTL delivery URL — provider URLs never reach the browser
iMessage lane: after trust-tier resolution in flush.ts; delivery order ported — validated bytes as native attachment, then a ≤10-word caption, then richlink/URL fallbacks
Composer palette: typing / lists the three commands with the reference's own descriptions; provider preflight joins cron/health
