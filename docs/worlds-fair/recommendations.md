# Recommended updates and changes — verified review of the World's Fair program

Produced 2026-10-12 by a 43-agent review: 8 auditors checked 273 concrete claims in `spec.md` against the code and the research notes (143 confirmed, 112 wrong, 18 unverifiable), 5 critics proposed 57 changes from distinct lenses (custody/security, judge demo value, Devin feasibility, product coherence, architecture fit), a merge pass deduplicated them to 14, two skeptics per recommendation tried to refute each one (all 14 survived, every one narrowed), and a synthesis ranked the result. The spec corrections in the appendix are applied to `spec.md`, `README.md`, and `docs/site/*.md` in the same commit as this file.

## Summary

The program is right in shape (one approval card, many chains; W0 then parallel sessions) but spec.md is not yet executable: 0141 copies stale constraint lists (0109 instead of 0125/0122), omits the users/user_chain_keys columns five sections read, writes states (`uncertain`, `redirected`) that wallet_transfers/payment_requests checks reject, and names a resolver (`resolvePayment`) and seams (`/pay` grammar "extension", `venueFor` switching on provider, `createOrder` replaying the preview) that do not exist. All 14 verified recommendations survived with zero refutations; every one was narrowed by its two skeptics and the narrowings are applied below. The headline moves: (R1) re-cut the plan so W0 is a full session that lands the whole 0141, then W1a/W2a/W3a/W5a run in parallel on fixture-green halves, with W4 last and the Rust binary (W5b) off the critical path; (R7/R8) make 0141 final SQL against the live schema and route every chain send through the existing run_approval→executeTransfer lane via `PayRail.submitSend`, deleting `resolvePayment`; (R2) a repo-conventions section (R-WF-0n commit ids, env manifest, viem 2.57.4 direct dep, kit 5.5.x, no @solana/pay, no WF_EVAL_FIXTURE) so each session's first CI run is green; (R11) rewrite §5 against the real TradeVenue/service.ts seams and the SDK's throw-on-error behavior; (R3/R10/R12) trim Tempo to send+memo+sponsor, receive watcher, MPP method and one per-charge machine payment, with standing budgets and the Box-callable auto-pay branch out of the window; (R9) tell the truth about the Zcash boundary (the agent account has root; sudoers is not the boundary). Tonight (13:21 PDT, ~10.5 h): fix spec/README text, run W0 (migration + seams + parser + env + deps), then W1a and W2a in parallel, W6 docs status pass, pre-seed the owner-only testnet steps now, and move anything unshipped under "not yet" before 23:00 PDT.
